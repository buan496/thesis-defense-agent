# 知识索引

## Python 与数据结构

| 概念 | 项目中的位置 | 已掌握内容 |
|---|---|---|
| list | `text_splitter.py`、`vector_store.py` | 顺序容器、append、切片 |
| dict | Tool Schema、metadata、report | 键值映射、get、嵌套结构 |
| JSON | 向量库、工具参数、评估报告 | 序列化与反序列化 |
| dataclass | `session_models.py`、`agent_models.py` | 结构化业务数据 |
| Callable | evaluator、tool、agent | 将函数作为依赖传入 |
| 闭包 | embedding cache | 内部函数访问外层状态 |
| 异常 | loader、tool executor、agent | 抛出、捕获、错误传播 |

## Agent

| 概念 | 含义 | 对应模块 |
|---|---|---|
| Tool | Agent 可调用的外部能力 | `tools/thesis_search.py` |
| Tool Schema | LLM 可理解的工具说明书 | `tools/definitions.py` |
| Tool Registry | 工具名到 Python 函数的白名单映射 | `tool_executor.py` |
| Tool Calling | 模型生成工具名和参数 | `agent.py` |
| Agent Loop | 调模型、执行工具、回传结果、继续推理 | `agent.py` |
| Harness | 承载循环、治理、轨迹、容错的运行外壳 | `agent.py` |
| Dependency Injection | 测试时替换 LLM 和工具 | `run_agent()` |
| Trace | 记录每次工具调用 | `agent_models.py` |
| Guardrail | 最大步数、参数范围、工具白名单 | Agent 与 Tool 层 |

## 计算机基础映射

### 计算机网络

- LLM 和 embedding API 使用 HTTP。
- TLS 握手超时曾导致 API 请求失败。
- 重试只能处理临时故障，不能修复错误 URL。
- 超时、连接池、状态码和幂等性将在异步阶段继续学习。

### 操作系统

- 虚拟环境隔离 Python 解释器和依赖。
- 文件路径、编码和换行属于操作系统差异。
- Agent 长任务需要理解进程退出、信号、临时文件和原子写入。
- `time.perf_counter()` 使用单调时钟测量耗时。

### 系统组成与软件工程

- config 是配置层。
- tools 是能力层。
- agent 是调度层。
- CLI 是交互入口层。
- tests 是质量保障层。
- data 是运行数据和缓存层。
- docs 是知识与设计层。
