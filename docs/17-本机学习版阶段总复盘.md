# 本机学习版阶段总复盘

## 阶段定位

本阶段总结当前机器上的 Thesis Defense Agent 学习版成果。

当前项目已经完成一个本机闭环的 Agent Harness 学习样板：

```text
论文文档
-> RAG
-> Tool Calling
-> Agent Loop
-> Session / Memory
-> DefenseTask 可恢复任务流
-> Sub-Agent 本地治理
-> LangGraph 旁路对照
-> Trace / Evaluation / CI
-> 文档化复盘
```

这个阶段的目标不是做成线上产品，而是系统掌握 Agent 工程的核心模块和边界。

## 可展示命令

```powershell
uv run pytest -q
```

### 构建向量库

```powershell

```

### RAG 评估

```powershell
python -m app.cli evaluate-rag --min-score 0.9
```

### 多轮 Chat

```powershell
python -m app.cli chat --message "请根据论文说明系统架构。"
```

### 完整 Task 流

```powershell
python -m app.cli create-task --topic 系统架构
python -m app.cli resume-task --task-id <TASK_ID>
python -m app.cli analyze-task --task-id <TASK_ID>
python -m app.cli export-task-markdown --task-id <TASK_ID>
```

### Memory 审计

```powershell
python -m app.cli memory-audit
python -m app.cli memory-hit-audit --query "系统架构"
python -m app.cli memory-context-report --query "系统架构"
```

### Trace 回放

```powershell
python -m app.cli replay-agent-trace
python -m app.cli replay-trace --file data/traces/agent_trace.jsonl --source-type agent
```

### Sub-Agent Dry-Run

```powershell
python -m app.cli dry-run-sub-agent-call `
  --sub-agent retrieval_agent `
  --tool search_thesis `
  --arguments "{\"query\":\"系统架构\",\"top_k\":3}" `
  --save-trace
```

### LangGraph 旁路对照

```powershell

  --topic "系统架构" `
  --thread-id "thread-1" `

  --follow-up-answer "这样可以把不同模块的问题分别定位。"

python -m app.cli graph-task-parity
```

## 下一阶段建议

服务器笔记本阶段建议顺序：

```text
1. FastAPI 服务化
2. 文件上传与任务 API
3. SSE / WebSocket 流式输出
4. PostgreSQL 存储 task / session / trace
5. Qdrant 或 Milvus 替换本地 JSON 向量库
6. Docker Compose
7. Prometheus / 日志 / 健康检查
8. MCP Server 实际接入
9. 权限审批和 workspace 隔离
```

本机项目保留为学习版基线，不直接改造成服务器版本。
