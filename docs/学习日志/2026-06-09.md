## 今天理解的核心概念

### Tool Calling 不等于执行工具

模型只负责输出：

```text
工具名 + 参数
```

Python Harness 负责：

```text
验证 → 执行 → 记录 → 回传
```

### Agent Loop

```text
用户输入
→ LLM 判断
→ 调用工具
→ 工具结果进入 messages
→ LLM 继续判断
→ 最终回答或继续调用
```

### Agent Harness

Harness 是 Agent 的工程运行外壳，负责：

- 消息历史
- 工具调度
- 最大步数
- 异常恢复
- 轨迹记录
- 依赖注入
- 测试能力

### 工具治理

- Schema 约束是给模型看的。
- Python 参数校验才是真实安全边界。
- Registry 是工具白名单。
- 不能使用 `eval()` 执行模型给出的工具名。
