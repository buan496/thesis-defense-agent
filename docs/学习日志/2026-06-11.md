## 核心概念

### Tool Routing

模型根据用户意图决定是否调用工具，以及调用哪个工具。

### Tool Chaining

前一个工具的结果成为后一个工具的输入。本项目中的工具链为：

```text
search_thesis
→ create_defense_questions
→ final answer
```

### 路由准确率

当前采用严格顺序匹配：

```text
actual_tools == expected_tools
```

工具相同但顺序不同，也会判定失败。

## Groundedness

### 今日新增

- 在 benchmark 中为关键事实定义 `grounding_rules`
- 将成功的 `search_thesis` 工具结果汇总为证据文本
- 分别检查声明是否出现在最终答案、证据关键词是否出现在检索结果
- 统计 `groundedness_score`、`grounded_task_rate`
- 增加 `end_to_end_grounded_success_rate`
- 增加 `--min-groundedness-score` 和 `--min-grounded-task-rate`
- 覆盖有证据、无证据、答案缺少声明、检索失败四类测试

### 指标区别

```text
Task completion
    最终输出是否满足格式与关键词要求

Groundedness
    最终输出中的关键声明是否能在检索证据中找到依据

End-to-end grounded success
    路由、参数、任务完成和内容依据是否全部通过
```

### 验证结果

```text
70 passed
TOOL ROUTING ACCURACY: 1.0

GROUNDEDNESS SCORE: 1.0

```

第一次真实门禁运行中，Groundedness 已通过，但普通问候出现了一次空回复，导致任务完成率下降。单独复测问候后模型正常返回，说明这是在线模型调用的非确定性，而不是 Groundedness 逻辑错误。

### 当前局限

第一版 Groundedness 使用预定义声明和关键词匹配，优点是稳定、可解释、可离线测试；局限是不能识别同义表达、否定关系、夸大结论或多个证据之间的错误组合。
