## 教学约定

1. 学生本人编写代码，除非明确要求“帮我改完”。
2. 每次只推进一个可验证的小步骤。
3. 每一步遵循：

```text
解释原理
→ 学生实现
→ 单元测试
→ 实际运行
→ 分析结果
→ 更新 Obsidian
→ Git 提交
```

4. 新概念出现时，同时讲解相关基础知识，包括数据结构、网络、操作系统和系统设计。
5. 不依赖聊天记忆判断进度，以当前源码、测试、Git 和本 Vault 为准。
